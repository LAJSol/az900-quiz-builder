# AZ-900 Quiz Builder (Unofficial)

A simple study tool for the Microsoft Azure Fundamentals (AZ-900) exam, built for the #1MillionDevs Vibe Coding Hackathon.

> Unofficial. Not affiliated with or endorsed by Microsoft. All questions are original and based on the public AZ-900 skills outline on Microsoft Learn.

## The problem
Many learners practise with questions but don't understand why an answer is right or wrong. When I studied for AZ-900, the knowledge checks at the end of the Microsoft Learn modules only marked my answers Correct or Incorrect, without explaining why. The Azure Architecture and Services module was a challenge for me.

## The solution
A quiz app that gives instant feedback and a clear explanation for every answer, organised by AZ-900 topic.

## What it does
- Pick an AZ-900 topic and answer multiple-choice questions
- Get instant feedback with an explanation of why each option is right or wrong
- See your score and review the questions you missed

## Built with
HTML, CSS and JavaScript, using Bolt.new and AI-assisted prompts.
